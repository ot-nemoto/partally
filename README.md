# partally

QR コードを読み込むだけで参加できる、宴会・イベント向けのアプリです。撮った写真をみんなで共有し、お気に入りやゲーム（クイズなど）でポイントを集めて、ランキングと景品で会場を盛り上げます。

- 参加者はスマートフォンのブラウザで使います（アプリのインストールは不要）。
- 幹事は PC またはスマートフォンのブラウザで、管理画面から進行します。

## できること

| 機能 | 内容 |
|---|---|
| かんたん参加 | 配られた QR コードを読み込み、名前を入れるだけ。ランダムな「二つ名」（例: 〈疾風の魔術師〉）が付きます |
| 写真の共有 | その場で撮るか、スマホの写真を選んで投稿。みんなの写真を一覧で見られます |
| お気に入り | 気に入った写真に ♡ を付けられます（枚数に上限あり） |
| ゲーム | クイズ（幹事が出した問題にスマホで答える。締め切りまで選び直せる）、数値予想（数を予想して答え、正解に近いほど高い点数）、投票（参加者の中から 1 人に投票し、票の多い人に点数）、合言葉（会場で見つけた言葉を入れ、早く正解した人に点数）、抽選（「参加する」を押した人から当たった人に点数）や、じゃんけん大会などの結果でポイントが入ります。開催中は画面の上にお知らせが出ます |
| ポイント | 写真の公開、お気に入りに選ばれる・選ぶ、ゲーム（クイズ・数値予想・合言葉の答え・投票・結果）でポイントが入ります |
| スケジュール | 進行表を見られます。今の時間の項目に「いま」、次の項目に「つぎ」が付きます（幹事が公開したとき） |
| ランキング・景品 | 順位やポイントの移り変わり、何位で何がもらえるかを見られます（幹事が公開したとき） |

## 参加者の使い方

1. **QR コードを読み込む**: 配られた QR コードを、スマホの**標準のカメラ**で読み込みます。
   - LINE などのアプリ内のカメラで開くと、次に開いたときにログインが切れることがあります。
2. **名前を入れる**: 初めてのときは名前を入れます。二つ名は自動で付きます。2 回目からは同じ QR コードで、すぐに開けます。
3. **写真を投稿する**: ホームの「撮影する」か「写真を選ぶ」から投稿します。
   - 電波が悪くて送れなかった写真は、スマホに残しておき、つながったときに自動で送り直します。送信待ちの枚数はホームに出ます。
   - 投稿した写真の状態（確認待ち・公開中・非公開）は「自分の写真」で確かめられます。幹事が公開しなかった写真は「非公開」になります。
   - 幹事の確認が終わるまで、ほかの人には見えないことがあります（「確認待ち」と表示されます）。
4. **お気に入りを選ぶ**: 「みんなの写真」で、ほかの人の写真の ♡ を押します。選べる枚数はホームに出ます。
5. **ゲームに参加する**: ゲームが始まると、画面の上にお知らせ（クイズ・数値予想なら「問題が出ています」、投票なら「投票受付中」、合言葉なら「合言葉を受付中」、抽選なら「抽選の参加受付中」、それ以外は「ゲーム開催中」）が出ます。押すとゲームの画面が開きます。
   - クイズは選択肢を選ぶと答えになり、締め切りまでは選び直せます。問題や選択肢に写真が付いていることもあります。
   - 数値予想は数（0〜100）を入れて「答える」を押します。締め切りまでは答え直せます。正解に近い順に順位が付き、順位ごとの点数は画面に出ています。
   - 投票は参加者の一覧から 1 人を選びます（名前・二つ名で探せます。自分には投票できません）。締め切りまでは選び直せます。誰に投票したかはほかの人には見えません。
   - 合言葉は、会場で見つけた言葉を入れて「送る」を押します。その場で正解か分かり、不正解なら何度でも試せます。早く正解した人ほど高い点数が入ります。
   - 抽選は「参加する」を押すだけです。締め切られたときにアプリが無作為に抽選し、当たった人にポイントが入ります。
   - じゃんけん大会などは、説明と、枠（優勝など）ごとの点数を見られます。結果は幹事が入れます。
6. **イベント情報を見る**: 幹事がスケジュール・ランキング・景品などを公開すると、画面下に「イベント情報」が出ます。

画面下の「更新」を押すと、最新の状態になります。

### ポイントの入り方

ポイントのルール（何をすると何ポイントか）は、ホームに表示されます。点数は幹事が決めます。

- 自分の写真が公開されたとき
- 自分の写真がお気に入りに選ばれたとき
- ほかの人の写真をお気に入りに選んだとき
- ゲームの結果が決まったとき（クイズなら選んだ答えの点数、数値予想なら順位の点数、投票なら選ばれた順位の点数と投票した点数、合言葉なら正解した順の点数、抽選なら当たった等の点数、じゃんけん大会などなら入った枠の点数。例: じゃんけん大会 優勝 +30、飴の数 2 位（予想 42） +5）

幹事の設定によっては、発表までポイントが隠されていることがあります。

## 幹事（管理者）の使い方

管理画面（`/admin`）に、管理者パスワードでログインして使います。

| 時期 | やること |
|---|---|
| 準備 | QR コードを発行して印刷する。ポイントの点数や写真の公開方法を決める。ゲーム（クイズなど）・景品・スケジュールを登録する |
| 当日 | 写真を確認して公開する。ゲームを開催して結果を確定する。ランキングを見ながら盛り上げる |
| 発表 | ランキングの移り変わりを再生する。参加者にランキングや景品を公開する |
| 終了後 | データを消す（担当者に依頼） |

画面ごとの使い方は [幹事向けガイド](docs/organizer-guide.md) を見てください。

## よくある質問

**QR コードをなくした・人に渡してしまった**
すぐに幹事に伝えてください。QR コードを持っている人は、あなたとしてログインできてしまいます。幹事が紐づけを外すと、その QR コードではあなたとしてログインできなくなります。外した後は、新しい QR コードで登録し直します（それまでのポイントは引き継がれません）。

**ログインが切れた**
同じ QR コードをスマホの標準のカメラで読み込み直してください。

**写真が「送信待ち」のまま**
電波のよい場所に移ると、自動で送り直します。送れずにエラーが出ているときは、ホームの「今すぐ再送」で、すぐに送り直すこともできます。

**写真が表示されない・ポイントが反映されない**
画面下の「更新」を押してください。写真は、幹事が確認してから公開されることがあります。
